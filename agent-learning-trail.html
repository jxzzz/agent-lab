Agent 学习地图

学 agent 的正确顺序:先徒手跑通模型调用和工具循环,再落地一个真实场景的单 agent,然后接外部知识(RAG),最后才碰多 agent。轨道上只放节点和站名——点开侧边栏看每站该学什么、动手做什么;带小圆的站点是主线走通后再拐进去的深入方向。

大圆 = 主线营地 小圆 = 深入分支 四片沼泽 · 绕开 
# agent 的全部秘密,10 行讲完——你在 fundamentals/ 里徒手写过一遍
while True:
    resp = llm(messages, tools=tools)
    if not resp.tool_calls:
        break                      # 模型说完了,收工
    for call in resp.tool_calls:
        result = run(call)          # 你的代码动手脚
        messages.append(result)     # 结果回炉,再问模型

模型提要求,代码动手脚,结果回炉再问。所有框架都是这个循环的包装——project-1/2/3 的 LangGraph、ai-sdk-lab 的 AI SDK,拆开全是它。

Swamps · 沼泽

别踩,踩了就陷进去

Swamp 01

从框架教程入门

你已经绕开了这个:先在 fundamentals 徒手写循环,再上 LangGraph。框架从此是工具,不是黑盒。

Swamp 02

迷信多 agent

project-3 拆了四个角色是因为任务真的需要。单 agent + 好工具能解决的事,拆成五个只会互相传错话。

Swamp 03

无 eval 调提示词

evaluate.py 的 4 条评估集是雏形——每次改 prompt 都先跑一遍,不然你只是在掷骰子。

Swamp 04

追求通用大脑

客服查单、知识库问答、报告生成——你的三个项目每个都窄而深。通用是无数个窄步走出来的。
